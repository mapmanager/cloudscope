# Quickstart

A typical CloudScope session is:

1. Launch the desktop app or open the browser app.
2. Load sample data or open local acquisition files.
3. Inspect images and metadata.
4. Create or review ROIs.
5. Run velocity or diameter analysis.
6. Inspect results in the GUI.
7. Copy results or save analysis outputs.

For first-time exploration, use the GUI menu item for loading sample data from the companion `cloudscope-data` repository.
