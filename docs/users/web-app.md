# Browser app

The CloudScope browser app is available at [cloudscope.mapmanager.net](https://cloudscope.mapmanager.net){target="_blank" rel="noopener"}.

The browser app is the easiest way to try CloudScope before installing the desktop application. The browser GUI uses the same backend code paths as the desktop app, which helps keep user-facing behavior consistent across deployments.

The browser app is also useful for quick demonstrations, reviewing sample data, and learning the basic workflow before committing to a desktop installation.
