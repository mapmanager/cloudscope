# Contributing

Contributions should preserve CloudScope's architecture rules: keep scientific logic in `acqstore`, reusable UI widgets in `nicewidgets`, and CloudScope-specific orchestration in `cloudscope`.

Before proposing a change, run tests locally and keep replacement files targeted to the files actually edited.

## Documentation

When editing pages under `docs/`, follow the [MkDocs style guide](mkdocs-style.md).
